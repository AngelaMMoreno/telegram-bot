una oposición.

Sirve para dos cosas:

1. **Auditar cobertura**: comprobar que cada epígrafe de las bases tiene
   contenido asignado y detectar huecos.
2. **Traducir**: las bases llaman a lo mismo de forma distinta en cada
   convocatoria. El nombre canónico del tema no cambia
